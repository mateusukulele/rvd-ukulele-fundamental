# Logo do Clube do Ukulele: pacote oficial em vetor

Vetorizado em 02/10/2026 a partir do arquivo mestre
(`Downloads/Logo Original - fundo transparente - Clube do Ukulele agosto 2026.png`) com potrace.
As letras, o ukulele, os raios e as asas são as formas do original; nada foi redesenhado à mão.

| Arquivo | Uso |
|---|---|
| `logo-clube-do-ukulele` | Escudo com asas, cores da marca. A assinatura principal. |
| `logo-clube-do-ukulele-indigo` | Escudo em uma cor (índigo profundo). |
| `logo-clube-do-ukulele-preta` | Escudo em preto, impressão P&B. |
| `logo-clube-do-ukulele-branca` | Escudo todo branco, fundo escuro ou foto. |
| `logo-horizontal` | Ukulele com raios ao lado do nome, cores da marca. Fundo claro. |
| `logo-horizontal-negativa` | Horizontal em branco com raios laranja. Fundo escuro. |
| `logo-horizontal-indigo` | Horizontal em uma cor. |
| `logo-horizontal-preta` | Horizontal em preto, impressão P&B. |
| `logo-horizontal-branca` | Horizontal toda branca. |

Cada um existe em `.svg` (qualquer tamanho, impressão, bordado) e `.png` transparente de 2000px.
Mínimos: escudo 96px / 2,5 cm; horizontal 120px / 3 cm. Regras completas no Manual Visual 2026, seção 2.
